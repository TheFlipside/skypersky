# Project: Skypersky

## What This Project Does

An application which looks like an Antivirus software but does not have a
function other than displaying a toggleable button to indicate a theoretical
active protection status.

## Stack

- **Language:** Flutter
- **Build:** flutter build appbundle --debug

## Directory Layout

```
lib/          → the application core logic
assets/       → media files for the app look
mockups/      → conceptual screenshots to guide how the final app should look like
```

## Essential Commands

```bash
# Build
flutter build appbundle --debug

# Lint (must pass before committing)
dart analyze .        # Flutter/Dart
```

## Project-Specific Rules

The app shall be available for many different platforms, therefore Flutter was
chosen as framework.
There is no function other than the displayed interface.
